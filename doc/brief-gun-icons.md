# 外包需求：哗变「手枪」图标组（Feed the Kraken 数字版）

> 项目：险恶疑航 / Feed the Kraken —— 基于同名桌游的线上版。
> 本需求面向插画师/图标设计师，只需交付一套图片资源（同主题 3 个变体）；
> 无需了解游戏代码。

---

## 1. 画什么

一套**燧发手枪（flintlock pistol）图标**，替代当前哗变（叛变表决）界面里
占位的 🔫 emoji。枪是本作「不满的船员亮枪逼宫」的核心意象，会出现在三处：

| 变体 | 用途 | 数量 |
|---|---|---|
| A. 单枪 | 通用图标：名册徽章、结果列表里按数量重复平铺 | 1 张 |
| B. 按钮态 | 表态按钮上与数字并排的版本（可能需要更粗剪影/描边，见 §2） | 1 张 |
| C. 点亮态 | 按钮被选中时的高亮版本（金色调 / 更亮的着色） | 1 张 |

A 与 B 可以是同一张（如果你判断通用版在按钮上效果已够好，请在交付时说明）；
C 必须单独调色。**三个变体构图、角度、细节完全一致，只有色彩状态不同**——
它们会在同一屏并排出现，不一致会像 bug。

**画面内容建议：**

- 一把 18 世纪燧发手枪，侧视图，**枪口朝左、枪托朝右**（与数字
  「🔫3」并排时读作「三把枪」，枪口背对数字更自然）；
- 深色木质枪托（深棕/近黑），暗色金属枪管，火药池/扳机处可有一点
  金黄或暗红点缀；
- 略带手绘质感即可（现有徽章类图标是手绘上色风），不要扁平单色矢量风、
  不要写实照片风；
- **不加文字、不加边框、不加底座、不加投影**——透明背景，图标会叠在
  深蓝色 UI 面板上。

**氛围**：风帆时代的海上哗变——不是可爱 emoji，也不必血腥；一把
「老水手从腰后拔出来的家伙」，旧金属和木头的质感、微微的威胁感。

## 2. 交付规格

| 项 | 要求 |
|---|---|
| 画布 | 每张 **PNG，透明背景，256×256**；三变体同画布同位置同大小 |
| 剪影安全区 | 枪体（含扳机护圈等突出物）在中心 ~80% 圆内，**宽度方向顶满更多**（横向武器，竖向留白可多） |
| 枪口方向 | 朝左（9 点方向），±10° 以内的俯仰均可 |
| 缩放可用性 | 眯眼剪影可辨「这是一把枪」；缩到 48×48 仍不糊成一团 |

游戏内实际显示尺寸：按钮里约 22–28px 高，徽章里约 14px，结果列表约 18px。
所以**剪影优先于细节**，256px 源文件缩到 48px 后必须依然可读。

## 3. 技术约束（为什么是这些数字）

- 图标压在深蓝色面板（`#141d30`）上，会被选中有金色描边高亮
  （金 `#d4a74a`）。请在深底上校色，避免纯黑剪影在深蓝底上糊住——
  金属部分建议留高光或亮边；
- 变体 C（点亮态）色调向金 `#d4a74a` 靠，或整体提亮一档，二选一即可，
  以深蓝底上对比明显为准；
- 交付：PSD/Procreate 源文件（分层）+ 3 张 256 PNG；若 A=B 请在交付
  说明里写明，此时只需 2 张 PNG。

## 4. 参考与风格对齐

- **风格基准**（同项目已有图标，请对齐做旧手绘质感与饱和度）：
  `ref-crest-lieutenant.png`（大副星徽）、`ref-crest-navigator.png`
  （领航员舵轮徽）——这两个是最接近的同类资产；
- 船只图标 `ref-ship.png` 供参考整体美术基调（海图墨线风）；
- 风格关键词：燧发枪 / 大航海时代 / 手绘做旧 / 暗色金属 + 深木托 /
  一点金色高光。

## 5. 验收标准

1. 三变体构图逐像素级对齐（仅色彩差异），并排显示无「换了把枪」感；
2. 透明背景，无文字/水印/图外投影；深蓝 `#141d30` 底上主体清晰；
3. 缩至 48×48 剪影可辨是枪；缩至 14px（徽章尺寸）不糊；
4. 变体 C 在深蓝底上比 A/B 明显更亮/更金；
5. 交付：源文件 + PNG（2 或 3 张，按 §3 约定）+ 每张一张 48×48 缩放
   自检截图。
