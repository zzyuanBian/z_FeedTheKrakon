# 外包需求：海图移动船只图标（Feed the Kraken 数字版）

> 项目：险恶疑航 / Feed the Kraken —— 基于同名桌游的线上版。
> 本需求面向插画师/图标设计师，只需交付一张图片资源；无需了解游戏代码。

---

## 1. 画什么

一张**顶视（俯瞰）帆船图标**，替代当前游戏地图上占位的 emoji 帆船（⛵）。
它表示「船队此刻的位置」，会沿航线逐格移动。

**画面内容建议：**

- 一艘帆船的俯视图：能看清甲板、张开的帆（或半收的帆）、船头方向；
- 风格与现有海图一致（见 §4 参考图）：做旧羊皮纸海图上的手绘墨线 +
  淡彩风格，线条略带不确定性（手绘感），不要扁平矢量感/描边图标风；
- 船体配色：深色木质船身（深棕/近黑），帆为米白/泛黄，可有少量暗红
  点缀（与海图的罗盘、航线装饰色呼应）；
- **不加文字、不加边框、不加底座、不加阴影投在图外**——图标需要叠在
  各种深浅的海面上，透明背景。

**氛围**：18 世纪风帆时代的神秘航行；游戏主题涉及深海怪物（克拉肯），
可在细节里藏一点不祥感（如船尾水面下一抹暗影轮廓），但不要喧宾夺主。

## 2. 交付规格

| 项 | 要求 |
|---|---|
| 主体图 | PNG，**正方形画布 1024×1024**，船头朝上（12 点方向） |
| 背景 | **透明**（只保留船及紧贴船体的水面涟漪，如有） |
| 安全区 | 船体（含帆桁等横向突出物）位于中心 ~80% 圆内 |
| 备选帧（可选加分项） | 同构图的「紧急航行」变体：帆全张 + 追赶的水花/倾斜，用于游戏进入紧急状态时替换 |

## 3. 技术约束（为什么是这些数字）

游戏地图原图 3300×3296，图标在地图上约占 **220×220 原图像素**
（屏幕上实际显示约 40–70px，随窗口缩放）。因此：

- 1024px 源文件缩到 220px 仍需线条清晰、剪影可辨——**剪影优先于细节**，
 眯眼能认出「这是一艘帆船」是硬标准；
- 船头必须朝上：代码里会按航线方向旋转图标（当前朝向即航行方向），
 旋转以图中心为轴；
- 最终交付同时给出 1024 源文件 + 一个已缩至 440×440 的预览版。

## 4. 参考与风格对齐

- 海图（图标最终落在这张图上）：`doc/brief/map-short.jpg`
- 当前占位效果（要被替换的对象，仅供理解用途）：地图中央偏右的 ⛵ emoji
- 风格关键词：手绘墨线海图 / 做旧羊皮纸 / 淡彩 / 大航海时代 / 一点克苏鲁式不祥

## 5. 验收标准

1. 透明背景下剪影清晰，缩至 88×88（约屏幕实际尺寸的 2 倍）仍可辨认是帆船；
2. 船头正上方，构图居中，四边无裁切；
3. 风格与海图 并置不违和（墨线粗细、色调、做旧程度相当）；
4. 无文字、无水印、无图外阴影；
5. 交付：PSD/Procreate 源文件 + 1024 PNG + 440 预览 PNG。
